# Learno-Mind

> Learno-Mind is an open-source data repository and central knowledge hub designed for students to organize, store, and share subject-wise academic resources, structured JSON vocabulary data, and study materials for interactive learning tools.

---

## Overview

**Learno-Mind** is designed to serve as a comprehensive public data store and central knowledge hub for HSC (Higher Secondary Certificate) students. Instead of scattering study materials, chapter notes, vocabulary lists, and practice resources across different places, this repository systematically organizes all academic data using a **Monorepo structure** grouped strictly by subject areas rather than raw file formats.

Its primary goal is to provide a clean, accessible, and well-structured resource repository where HSC students can easily find subject-wise study materials, lecture notes, and practice sets to streamline their preparation.
